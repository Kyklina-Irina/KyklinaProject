# 🍲 KyklinaProject — Калькулятор порций супа

Консольное приложение на **Java** для расчета количества ингредиентов супа на одного человека.

## 📋 Описание

Это учебный проект, демонстрирующий основы работы с Java:
- Объявление и использование переменных
- Арифметические операции (деление)
- Вывод данных в консоль
- Базовая структура Java-программы

Программа рассчитывает, сколько воды, картофеля, куриных бёдер и специй достанется каждому человеку при готовке супа на компанию.

## 🛠 Технологический стек

- **Язык:** Java
- **Тип приложения:** Консольное приложение
- **IDE:** IntelliJ IDEA
